# Manga List 2018

My first personal manga list web tool, built from scratch with a custom PHP framework. A nostalgic journey from 2018 where I learned by building my own framework to manage and track my manga collection.

## 📖 About

This project represents my first foray into building a complete web application for managing manga lists. Rather than using an existing framework, I challenged myself to create a custom PHP framework from the ground up, learning fundamental web development concepts along the way.

Built with passion and curiosity in 2018, this project served as both a practical tool for tracking my manga reading and an educational experience in web architecture.

## ✨ Features

- Personal manga collection management
- Track reading progress and status
- Custom-built PHP framework (no Laravel, no Symfony - just pure PHP architecture)
- Database-driven manga storage and retrieval
- User-friendly interface for managing your manga list

## 🛠️ Technologies Used

- **PHP** - Core backend language
- **Custom PHP Framework** - Built from scratch for this project
- **MySQL** - Database management
- **HTML/CSS** - Frontend markup and styling
- **JavaScript** - Client-side interactivity

## 🏗️ Custom Framework Architecture

This project features a home-grown PHP framework built to understand core MVC concepts:

- Custom routing system
- Database abstraction layer
- Template rendering engine
- Request/response handling
- Session management

*Note: This was a learning project. For production applications, consider using established frameworks like Laravel or Symfony.*

## 📦 Installation

To run this project locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/leopaul29/Manga-list-2018.git
   cd Manga-list-2018
   ```

2. **Set up your environment**
   - Ensure you have PHP 7.0+ installed
   - Set up a MySQL database
   - Configure your web server (Apache/Nginx)

3. **Configure database connection**
   - Update the database configuration file with your credentials
   - Import the database schema (if provided)

4. **Start your local server**
   ```bash
   php -S localhost:8000
   # or configure your Apache/Nginx virtual host
   ```

5. **Access the application**
   
   Navigate to `http://localhost:8000` in your browser
